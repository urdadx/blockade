# Install Blockade on Microsoft Edge

Blockade is distributed for Edge as a Manifest V3 extension.

## Installation

1. Download [`extension-0.0.1-edge.zip`](https://github.com/urdadx/blockade/releases/download/v0.0.1/extension-0.0.1-edge.zip).
2. Extract the ZIP file to a permanent folder. Edge loads the extension from this folder, so do not delete it after installation.
3. Open `edge://extensions` in Edge.
4. Enable **Developer mode** in the left sidebar.
5. Select **Load unpacked**.
6. Select the extracted folder containing `manifest.json`.
7. Pin Blockade from Edge's Extensions menu for quick access.

## Updating

1. Download and extract the newer Edge release into a new folder.
2. Open `edge://extensions`.
3. Remove the existing Blockade installation.
4. Select **Load unpacked** and choose the new folder.

Edge may display a developer-mode warning because this release is installed outside Microsoft Edge Add-ons.
