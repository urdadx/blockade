# Install Blockade on Google Chrome

Blockade is distributed for Chrome as a Manifest V3 extension.

## Installation

1. Download [`extension-0.0.1-chrome.zip`](https://github.com/urdadx/blockade/releases/download/v0.0.1/extension-0.0.1-chrome.zip).
2. Extract the ZIP file to a permanent folder. Chrome loads the extension from this folder, so do not delete it after installation.
3. Open `chrome://extensions` in Chrome.
4. Enable **Developer mode** in the upper-right corner.
5. Select **Load unpacked**.
6. Select the extracted folder containing `manifest.json`.
7. Pin Blockade from Chrome's Extensions menu for quick access.

## Updating

1. Download and extract the newer Chrome release into a new folder.
2. Open `chrome://extensions`.
3. Remove the existing Blockade installation.
4. Select **Load unpacked** and choose the new folder.

Chrome may display a developer-mode warning because this release is installed outside the Chrome Web Store.
